Build a Blog with Handlebars and Express

This is a simple blog application using Express and Handlebars. 
The blog will allow users to view a list of posts, see individual post details, and add new posts through a form.

Use the script: "npm run dev: build" in Terminal to start the server located at 'http://localhost:3000/'.
You will then be able to add a new post by using the form. Just add a title and some content, then push 'Add Post'.

At the bottom of the screen will be a list of all posts. If you were to select 'Read More' then you'll see the full post details. 
You can go to specific posts by directing to http://localhost:3000/post/:id as long as you're using a valid post ID.
